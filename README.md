# Clinical Analysis of Heart Disease Risk Factors

## Project Overview
This project performs an exploratory data analysis (EDA) on clinical patient data to identify key risk factors associated with cardiovascular disease. 

## Dataset
The dataset contains medical examinations of patients, including vitals (blood pressure, cholesterol), lifestyle factors (smoking, exercise), and the presence of heart disease.

## Tools Used
*   **Python** (Pandas, NumPy)
*   **Data Visualization** (Matplotlib, Seaborn)
*   **Environment** (Google Colab)

## Key Objectives
*   Clean and preprocess clinical data.
*   Visualize the correlation between lifestyle choices and heart disease.
*   Provide clinical interpretations of the statistical findings.
